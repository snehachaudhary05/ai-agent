8.  Short Description of the Work:

    Sitekraft is an AI-powered full-stack web application jointly developed by
    Sneha Chaudhary and Koustubh Kukreti, with academic guidance from their
    college mentor. The application enables users to generate complete,
    production-ready React/Vite websites from natural language descriptions
    through a conversational chat interface. The system integrates with Google
    Gemini 2.5 Flash (AI engine) to generate component-based React code, fetches
    relevant stock images from Pexels and Pixabay APIs, generates professional
    AI-written copy, and automatically deploys the generated website to Vercel
    with a live URL — all within a single conversational session.

    The software comprises:
      (a) A Python/FastAPI backend — including an autonomous AI agent, React
          code generator, Vercel deployment module, stock image helpers, and
          professional copywriting module.
      (b) A React/Vite frontend — including a conversational chat UI, multi-step
          onboarding flow, live preview, theme switching, and deployment status
          display.

    NOTE ON AUTHORSHIP: The mentor provided academic supervision and guidance
    only, and does not hold authorship or copyright in the work. All original
    code, design, and creative expression were authored exclusively by
    Sneha Chaudhary and Koustubh Kukreti in equal measure.
